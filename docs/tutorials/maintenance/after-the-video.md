# After the video — do this

Watch the video once. Then do these steps in order.  
Works on a **Mac** or a **Windows** laptop. Tick each box when done.

Shareable page (open in a browser): [`after-the-video.html`](after-the-video.html)

---

## 1. Get a GitHub account

- Open https://github.com/login  
- Sign in with **your own** account  
- Do not share your password  

## 2. Open the team project

- Open https://github.com/heaventech1984/comms_events_v1  
- If you cannot see it, ask to be invited. Stop until you can open it.  
- At the top, the branch should say `experiment`  

## 3. Install three free tools

- **Git** — https://git-scm.com/downloads  
- **Node** — https://nodejs.org (LTS button)  
- **Cursor** — https://cursor.com  
  (or free **VS Code** — https://code.visualstudio.com)  
- In Cursor / VS Code, sign in to GitHub as **you**  

## 4. Copy the project onto your laptop

Open Terminal (Mac) or Command Prompt / PowerShell (Windows).  
Go to the folder where you keep projects. Paste **one line**:

```bash
git clone -b experiment https://github.com/heaventech1984/comms_events_v1.git gather
```

Wait until it finishes. You now have a folder called `gather`.

## 5. Open that folder in Cursor

- **File → Open Folder** → choose `gather`  
- Open the bottom **Terminal**  
- Paste: `git status`  
- You want to see the word `experiment`  

## 6. Use the chat helper — you do not write code

- Open **Chat** → choose **Agent**  
- Type plain English, for example:  
  `I am new. Explain where I am. Do not edit files yet.`  
- If it goes too fast: `Stop. One step only. Wait.`  

**You decide. The helper helps.**

## 7. Three words for team work

| You say | Meaning |
| --- | --- |
| **Save** | Keep today’s work on your laptop |
| **Share** | Send it to GitHub |
| **Ask for a check** | Open a Pull request so someone reviews it |

Only when **you** say those words. The helper waits.

## 8. Look at Pull requests on GitHub

- Open https://github.com/heaventech1984/comms_events_v1/pulls  
- Empty list is fine on day one  
- Later: comments and reviews live here  

---

**Stuck?** Copy the exact error. Paste into Cursor Chat:  
`Explain in plain words. Wait.`
