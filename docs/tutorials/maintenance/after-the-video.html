Gather

After the video — do this

Watch the video once. Then do these steps in order. Works on a Mac or a Windows laptop. Tick each box when done.

1 Get a GitHub account

Open https://github.com/login

  • Sign in with your own account.
  • Do not share your password.

2 Open the team project

Open this link (ask the teacher if it changed):

https://github.com/heaventech1984/comms_events_v1

  • If you cannot see it, ask to be invited. Stop until you can open it.
  • At the top, the branch should say experiment.

3 Install three free tools

  • Git — https://git-scm.com/downloads
  • Node — https://nodejs.org (pick the LTS button)
  • Cursor (recommended) — https://cursor.com
    or free VS Code — https://code.visualstudio.com

In Cursor / VS Code, sign in to GitHub as you.

4 Copy the project onto your laptop

Open the Terminal (Mac) or Command Prompt / PowerShell (Windows).

Go to the folder where you keep projects, then paste this one line:

git clone -b experiment https://github.com/heaventech1984/comms_events_v1.git gather

  • Wait until it finishes.
  • You now have a folder called gather.

5 Open that folder in Cursor

  • File → Open Folder
  • Choose the gather folder
  • Open the bottom panel: Terminal

Paste this to check you are in the right place:

git status

You want to see the word experiment.

6 Use the chat helper — you do not write code

  • Open Chat in Cursor.
  • Choose Agent (the mode that can edit files).
  • Type plain English. Example:

I am new. Explain where I am. Do not edit files yet.

  • Read what it says.
  • If it goes too fast, type: Stop. One step only. Wait.

You decide Helper helps

7 Three words for team work

Save Share Ask for a check

  • Save = keep today’s work on your laptop (commit).
  • Share = send it to GitHub (push).
  • Ask for a check = open a Pull request on the website so someone reviews it.

Only do Save / Share / Check when you say so. The helper must wait for those words.

8 Look at Pull requests on GitHub

On the project page, click Pull requests.

Open: https://github.com/heaventech1984/comms_events_v1/pulls

  • Empty list is fine on day one.
  • Later, this is where you leave comments and approve work.
Stuck? Copy the exact error text. Paste it into Cursor Chat. Type: Explain in plain words. Wait. Do not guess. Do not force anything.
