# Maintain Gather — start here

For someone who has **never** opened this project on their laptop.

Picture: this folder is a **recipe shelf**. Fill the address card first. Then cook.

## 0. Fill the project card once

**[project.md](project.md)** — central place for `HOST` / `ORG` / `REPO`.

- **You** = your own GitHub login  
- **`ORG`** = the **central** GitHub home that owns the shared repo  
- Everyone is invited there; all changes go through that one repo
